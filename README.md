# Global-Economic-Indicators-Dashboard

## PROJECT OVERVIEW
The Global Economic Indicators Dashboard provides a comprehensive analysis of key economic metrics across multiple countries and years. The dashboard focuses on important indicators such as GDP, inflation, unemployment, and population to help understand economic trends and relationships between these factors.

This project demonstrates how data visualization can be used to transform raw economic data into meaningful insights that support economic analysis and decision-making.

## OBJECTIVE
- Analyze global GDP trends over time
- Compare economic strength across different countries
- Study the relationship between inflation and unemployment
- Provide a clear and interactive visualization of key economic indicators

## DATA SOURCES
- Source: Excel
- Data Includes:
  - Year – Time period of the economic data
  - Country – Country name
  - GDP_Billion_USD – Gross Domestic Product in billion USD
  - Inflation_Percent – Annual inflation rate
  - Unemployment_Percent – Percentage of unemployed workforce
  - Population_Millions – Total population in millions

The dataset contains 500 rows of economic data.

 ## KEY KPIs AND INSIGHTS

### Key KPIs
- Total Global GDP
- Average Global Inflation Rate
- Average Global Unemployment Rate
- Total Population

### Key Insights
- Certain countries contribute significantly more to global GDP (like Japan, China), indicating stronger economies.
- GDP trends fluctuate over time, showing periods of economic growth and decline.
- The scatter plot helps visualize potential relationships between inflation and unemployment, which can indicate economic stability or stress.
- Population size can influence the scale of economic activity in different countries.

## TOOLS USED

- **Excel** – Data source 
- **Power BI Desktop** – Data modeling & visualization  
- **Power Query** – Data cleaning and transformation  
- **DAX** – Measures and calculations

## CONCLUSION
